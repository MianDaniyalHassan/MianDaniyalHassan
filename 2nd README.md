## Flagship Projects

> Ordered by engineering quality, not upload date. Tech stacks verified from actual source code.

### 🎬 [Cinema Management System](https://github.com/MianDaniyalHassan/Cinema-Management-System-FullStack) — Full Stack

A complete cinema management dashboard with **React 18 + Vite + Tailwind** frontend and **Flask REST API** backend connected to **Microsoft SQL Server** via pyodbc. 672-line backend with 18+ API endpoints, raw SQL (no ORM), CRUD on 8 entities (movies, customers, bookings, screens, tickets, employees, tuck shop, parking). Normalized 3NF schema with foreign keys and multi-table JOINs.

`Flask` `React 18` `SQL Server` `pyodbc` `Tailwind CSS` `Vite` `Framer Motion`

---

### 🧠 [AI Persona Mapper](https://github.com/MianDaniyalHassan/Ai-Persona-Mapper) — AI / NLP

A rule-based NLP system that analyzes free-text to extract 7 personality traits (Focus, Chaos, Energy, Discipline, Openness, Socialness, NightOwlness), detect themes across 10+ categories, simulate habit curves, and generate exportable persona cards. **No LLM APIs** — everything runs locally with custom tokenization, keyword dictionaries, and weighted scoring formulas. Modular `core/` architecture with 7 independent modules.

`Streamlit` `pandas` `numpy` `matplotlib` `Custom NLP` `Rule-based scoring`

---

### 🎵 [AI Mood Playlist Generator](https://github.com/MianDaniyalHassan/AI-mood-playlist-generator) — AI / Recommendation

A 2185-line Streamlit app that takes natural language mood input, runs fuzzy matching via `SequenceMatcher`, maps to mood categories, and generates playlists from a built-in song dataset. Features dark/light mode, animated CSS song cards, and responsive design. **No API keys needed.**

`Streamlit` `pandas` `difflib` `seaborn` `matplotlib`

---

### 🤖 [My Jarvis](https://github.com/MianDaniyalHassan/My-Jarvis) — Voice AI

A voice-controlled assistant that listens via `speech_recognition`, processes commands (open websites, play YouTube music), and for complex questions — **automates Perplexity AI via Selenium** (undetected Chrome), scrapes the response, and reads it back using Google TTS + pygame. Also has a HuggingFace Mistral-7B client.

`speech_recognition` `gTTS` `pygame` `Selenium` `undetected-chromedriver`

---

### 🎌 [Anime Recommender v2](https://github.com/MianDaniyalHassan/anime-recommender-system-2nd-Version) — ML / Recommendation

Content-based recommendation engine with modular architecture — separate modules for config, data loading, recommendation (TF-IDF + cosine similarity via scikit-learn), plotting, and an interactive searchable/sortable/paginated anime table.

`Streamlit` `scikit-learn` `pandas` `matplotlib`

### 👁️ Aegis Eye — Computer Vision (FYP, in progress)

Road accident detection system using computer vision and deep learning. Real-time video analysis for accident identification with alert generation. *Repositories are private during development; a collaborative fork is [available here](https://github.com/MianDaniyalHassan/abu-bakar-ki-repo-Aegis-Eye).*

## Engineering Philosophy

I learn by building, not by watching tutorials. Every project in my repos exists because I wanted to understand something — how BSTs model social networks, how Flask talks to SQL Server, how you can automate a browser to query an AI and read back the answer. I write documentation because if I can't explain how something works, I probably don't understand it well enough. I prefer rule-based systems when they're sufficient and reach for ML when they're not.
