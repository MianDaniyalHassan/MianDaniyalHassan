## 💡 &nbsp;`> engineering_philosophy`

```python
class DaniyalApproach:
    def learn(self, topic):
        project = self.build_something(topic)     # learn by building, not watching
        self.document(project)                     # if I can't explain it, I don't get it
        return project

    def choose_tool(self, problem):
        if rule_based_is_sufficient(problem):
            return "custom implementation"         # no ML hammer for every nail
        return "machine learning"

    def ship(self, project):
        project.add_readme()                       # documentation is engineering
        project.add_setup_guide()                  # if it can't be reproduced, it doesn't count
        return project
```
